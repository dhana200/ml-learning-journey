# ML Learning Journey

Welcome to a beginner-friendly machine learning roadmap and learning materials repository. This repo is designed to help new learners discover key ML concepts through practical examples, clear progression, and easy-to-follow notebooks.

## What’s inside

- 🚀 Beginner-friendly learning path for machine learning fundamentals
- 📘 Hands-on notebooks for regression, classification, and data preparation
- 📊 Real datasets to practice and explore ML workflows
- 🧠 Simple explanations and step-by-step examples for learners

## Repository structure

- `2 - Regression/` — linear regression examples with real insurance data
- `3 - Classification/` — logistic regression and classification practice
- `4 - Data Prep/` — data preparation and multiple linear regression notebooks

## Why this repo

This repository is perfect for beginners who want a visible, organized starting point for machine learning. It emphasizes practical learning, easy navigation, and approachable examples to build confidence quickly.

## Get started

Open the notebook files in each folder and follow the step-by-step analysis. Start with regression, then move to classification, and finish with data preparation to complete the beginner roadmap.

Happy learning! 🎓
